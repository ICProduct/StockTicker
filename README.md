# 5 秒股價追蹤器（Chrome Extension）

一個零依賴的 Chrome Manifest V3 擴充功能。打開工具列上的彈出視窗後，會每 5 秒向 Yahoo Finance 更新所有已加入股票的報價。

輸入中文公司名稱（例如「台積電」）時，會使用證交所（TWSE）及櫃買中心（TPEx）的官方公司清單顯示候選項；也可以直接輸入完整股票代號。官方清單會在本機快取 24 小時。

## 安裝

1. 在 Chrome 開啟 `chrome://extensions/`。
2. 開啟右上角的「開發人員模式」。
3. 點擊「載入未封裝項目」。
4. 選擇本專案資料夾。
5. 將擴充功能釘選到工具列，點擊圖示開始使用。

## 股票代號

- 台灣上市：`2330.TW`
- 台灣上櫃：`6488.TWO`
- 美國股票：`AAPL`
- 日本股票：`7203.T`

按下輸入框右側的 `+` 可以將股票加入下方清單，既有股票不會被取代。股票清單會儲存在 Chrome 本機儲存空間，下次打開會自動沿用。

每張報價卡右上角的 `−` 可以單獨移除該項追蹤；即使移除全部股票，重新開啟時也會維持空清單。

按住報價卡並上下拖曳即可調整追蹤順序，放開後會自動保存。拖曳後的新第一筆股票也會成為 ICON 徽章顯示的標的。

搜尋框下方提供追蹤分頁，按分頁列右側的 `+` 可建立新頁。新增股票會放在目前分頁；把卡片拖到另一個分頁按鈕上即可移動並切換到該頁。設定面板可以替目前分頁輸入最多 3 個字的名稱，留空則顯示頁碼。每頁名稱、卡片順序與目前頁面都會保存。

點擊報價卡內容會開啟該股票的詳細頁。可由標題列的設定按鈕選擇台灣 Yahoo 股市或玩股網；玩股網僅用於台股，海外股票會自動使用台灣 Yahoo 股市。

新增股票前會先向報價服務驗證代號，找不到有效報價、服務拒絕或驗證逾時時都不會建立追蹤卡片。

清單第一筆股票的最新價格會以白色數字顯示在 Chrome 工具列的擴充功能 ICON 徽章上；移除第一筆後會自動改為下一筆。徽章保留最後一次成功更新的價格，開啟彈出視窗時會每 5 秒同步更新。漲跌顏色採台灣市場慣例：紅色上漲、綠色下跌。

每張報價卡中央會顯示最近 16 根一分鐘 K 線與成交量柱；紅 K 代表上漲、綠 K 代表下跌，圖表會跟隨報價同步更新。

台股可以只輸入數字代號，例如 `2330`；擴充功能會根據官方名單自動轉換為 `2330.TW`，上櫃股票則自動加上 `.TWO`。

## 注意事項

- 每 5 秒發出一次查詢，但實際成交資料更新速度取決於交易所與 Yahoo Finance。
- 輪詢只在彈出視窗開啟時執行；關閉視窗即停止，不會在背景持續耗用網路。
- 中文名稱比對目前涵蓋台灣上市與上櫃公司；英文名稱及其他市場仍透過 Yahoo Finance 搜尋。
- Yahoo Finance 公開端點可能有延遲、暫時限流或日後變更，請勿將此工具作為交易決策的唯一依據。
